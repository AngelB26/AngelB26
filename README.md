## 🏭 Industrial Document Intelligence Platform

*Production system at an industrial manufacturing company. I lead a 3-person team and own the architecture, LLM pipeline, and backend. The code is proprietary, so I'm happy to discuss the design in an interview.*

- Classifies uploaded industrial documents by type of standard and stores them in a structured database
- Extracts structured requirements with LLMs (Google Gemini, OpenAI), with a human approval step before anything is saved
- Reuses approved results, so repeat requests skip re-extraction and reduce LLM API cost
- Built to be configurable across industries, not tied to a single client
